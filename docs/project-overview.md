# 청년친구 프로젝트 개요

> 생성일: 2026-01-15 | 스캔 레벨: Exhaustive

## 프로젝트 소개

**청년친구**는 정부·지자체 청년 혜택을 한 번에 묶어 보여주는 맞춤형 모바일 앱입니다.

### 핵심 가치

- 청년 정책 정보의 접근성 향상
- 개인 상황에 맞는 맞춤형 혜택 추천
- 신청 마감 알림으로 놓치지 않는 혜택 관리

---

## 기술 스택 요약

| 카테고리 | 기술 |
|---------|------|
| 프레임워크 | Expo SDK 54 + React Native 0.81 |
| 언어 | TypeScript 5.9 |
| 라우팅 | Expo Router (파일 기반) |
| 상태 관리 | React useState (현재) |
| 스타일링 | StyleSheet + 디자인 토큰 |
| 애니메이션 | React Native Reanimated |

---

## 아키텍처 타입

- **Repository 유형:** Monolith (단일 코드베이스)
- **프로젝트 유형:** Mobile
- **아키텍처 패턴:** Component-Based Mobile Architecture

---

## 현재 기능

### 1. 온보딩 (`/onboarding`)

3단계 질문으로 사용자 페르소나를 파악합니다:
1. 관심 분야 선택 (주거, 커리어, 교육, 지역생활, 창업)
2. 거주 지역 선택 (서울, 부산, 광주, 대전, 제주)
3. 목표 선택 (전세/주거 안정, 취업·이직, 생활비 절약 등)

### 2. 홈 탭 (`/`)

- **추천 혜택 섹션:** 프로필 기반 큐레이션
- **빠른 작업:** 온보딩, 즐겨찾기, 체크리스트 바로가기
- **페르소나 하이라이트:** 자립 준비형, 커리어 도약형 설명

### 3. 탐색 탭 (`/explore`)

- **데이터 소스 목록:** 정부24, 서울시, 고용노동부 API
- **개발 로드맵:** 4주 단위 개발 계획

---

## 계획된 기능

### API 연동 (Week 2)

| 소스 | 설명 | 동기화 |
|------|------|--------|
| 정부24 청년정책 통합공고 | 전국 단위 청년정책 | 매일 02:00 |
| 서울시 열린데이터광장 | 지역별 지원 공고 | 3시간 간격 |
| 고용노동부 청년센터 | 취업 연계 프로그램 | 실시간 Webhook |

### 알림 및 체크리스트 (Week 3)

- 마감 이벤트 알림
- 신청 체크리스트 저장소

### 베타 배포 (Week 4)

- EAS Build로 스토어 제출 준비
- 지자체 제휴 스폰서 실험

## 프로젝트 구조

```
youth-friend/
└── app/                    # Expo React Native 앱
    ├── app/                # 라우트 (Expo Router)
    ├── components/         # 재사용 컴포넌트
    ├── design-system/      # 디자인 토큰
    ├── constants/          # 상수
    ├── hooks/              # 커스텀 훅
    └── assets/             # 에셋
```
