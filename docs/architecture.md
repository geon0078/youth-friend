# 청년친구 아키텍처 문서

> 생성일: 2026-01-15 | 스캔 레벨: Exhaustive

## 1. 개요

청년친구는 Expo + React Native 기반의 크로스 플랫폼 모바일 앱입니다. 정부·지자체 청년 혜택 정보를 수집하여 사용자에게 맞춤형으로 제공합니다.

### 핵심 원칙

- **크로스 플랫폼:** iOS, Android, Web 동시 지원
- **컴포넌트 기반:** 재사용 가능한 UI 컴포넌트
- **디자인 시스템:** 일관된 시각적 언어
- **파일 기반 라우팅:** 직관적인 네비게이션 구조

```
│  └───────┼────────────┼────────────┼────────────┼───────┘  │

```

### 레이어 설명

1. **App Layer (라우트)**
   - Expo Router로 관리되는 화면들
   - 파일 기반 라우팅으로 URL 경로 자동 생성
   - 각 화면은 독립적인 컨테이너

2. **Component Layer**
   - 재사용 가능한 UI 컴포넌트
   - 디자인 시스템 컴포넌트 (Card, Badge, Chip 등)
   - 유틸리티 컴포넌트 (ThemedText, IconSymbol 등)

3. **Design System Layer**
   - 색상, 타이포그래피, 레이아웃 토큰
   - 라이트/다크 모드 시맨틱 컬러
   - 일관된 시각적 언어 정의
